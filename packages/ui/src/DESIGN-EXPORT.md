# Claude Design export

These files come from the Opsell design system in Claude Design, exported on 2026-10-17:

- `styles/opsell-tokens.css`
- `styles/opsell-tailwind.css`
- `opsell-tokens.json`
- `format.ts`
- `status.ts`

Do not hand-edit them: change the design system in Claude Design, re-export, and replace these files.
The only edits after export are the "Generated by Claude Design" header on each file and the removal of the `LOCATIONS` demo data from `status.ts`, which belongs to the demo scenario ([#123](https://github.com/Opsell1/opsell/issues/123)).
The export's Tailwind v3 preset is left out, since the web app uses Tailwind v4 through `opsell-tailwind.css`.
Where `status.ts` disagrees with the spec ([#66](https://github.com/Opsell1/opsell/issues/66)), the spec wins until the next export fixes it.

These files are excluded from Biome by path in the root `biome.json`, so formatting never rewrites them.
`format.ts` does not typecheck under the repo's `noUncheckedIndexedAccess` (it destructures `split()` results), so `packages/ui` neither typechecks nor exports it for now; fix it in Claude Design and re-export, then add it back to the package exports.

Everything else in `packages/ui` is hand-written on top of these files.
